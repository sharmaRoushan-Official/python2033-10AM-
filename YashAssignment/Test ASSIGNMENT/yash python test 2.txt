Q11. Write Rules of Overriding? 
 
=>In Overriding it has the same method name of parent class with respect to child class and provide its own implementation.
  
 - method names should be same 
 - parameters should be same
 - need to have different class 
 
ex- class animal():
       def sound(self):
           print("animal sound")
    class dog(animal):
       def sound(self):
           print("dog barks")
    class cat(animal):
       def sound(self):
           print("cat meow:)
d=dog()
d.sound
c=cat()
c.sound

Q13. How many steps to read a file using python? Write steps? 

=> to read a file in python:
  1. first create a variable store the file path in it
  2. then open the variable/file using open() with mode 'r'
  3. then read the file using read()
  4. print the content of that file 
  5. close the file using close()


Q14. How many steps to write a file using python? Write steps? 

=> to write a file in python:
  1.first create a variable store the file path in it
  2. then open the variable/file using open() with mode 'w'
  3. then write the file using write()
  4.close the file using close()
