def word_palindrome(word):
    
    revWord = "" 
    for j in word:
        i = j.lower()
        revWord = i + revWord
    print("Reverse Word:",revWord)
    
    if word.lower() == revWord:
        print("Palindrome")
    else:
        print("Not Palindorme")

Q.19 What is polymorphism? Explain in details.

Polymorphism is defined as;

A child class redefines a method that is already exists in parent class.
Polymorphism using One Function for Different Object (Duck Typing)
Method Overriding in Python is where a child class provides its own implementation of a method that is already defined in the parent class.
Selection deleted
#Example:

class Animal:
    def sound(self): 
        print("Animal Makes a sound")

class Dog(Animal):
    def sound(self):
        print("Dog Barks")  # overriding


class Cat(Animal):
    def sound(self):
        print("Mew")    # overriding


d = Dog()
d.sound()

c = Cat()
c.sound()

Dog Barks
Mew

Polymorphism uses Operator Overloading:
Same operator behaves differently depending on datatype.
