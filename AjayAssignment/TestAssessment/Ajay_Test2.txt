Q2. Overloading: 
                is defined as accumulation of data and data type, as the name explains it accumulates multiple data and its type whether with same operator or multiple operator in a single class.
* Child class possesses, same operator behaves differently as per the Data type.

Overriding: 
           is overwriting or modifying the parent class to a new child class which possesses updated advanced or new logic than the parent class.
* It cannot be achieved in a single class as overloading does as it requires two or more/multiple class to assign the modification or change in the child class.
* In run time Python decides which method to execute.

Q3. Encapsulation:

Encapsulation means wrapping of data and method together in a single unit(class) and restricting direct access to the data.

Encapsulation = Data Hiding + Data protection
Without Encapsulation data is unsafe, no control, have bugs,etc.
With Encapsulation data is Protected, Controlled, Secured,etc.
Example : ATM Machine: => Cannot access data/account directly. => Need a method to access. => Balance is hidden.

Q11. Rules of Overriding:

1. Parent and child method names must be same.
2. Signature should be same i.e same Method name and Parameters.
3. Overriding is possible only if there is an inheritance between parent and child class.
4. As the name suggests child method overwrites/overrides the parent method an only child method is executed.

Q12. Super in OOPs:

* Super is used to call the Parent class method in the child class.
* Thus it has features of Parent class as well as added/updated functions of the child class in it.
