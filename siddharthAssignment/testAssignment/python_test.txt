    elif age > 18 and age <60:
        print("Adult")
    elif age > 60:

Q2. Write a Function to Check is string is palindrome.

def check_palindrom(string):
    if string == string[::-1]:
        print(f"{string} is a palindrom")
    else:
        print(f"{string} is not a palindrom")



check_palindrom("ABAD")

Q4. Write a function to find the sum of numbers from 1 to N.

def find_sum(n):
    sum =0
    for i in range(1,n+1):
        sum +=i
    print(f"Sum is :{sum}")


find_sum(5)

Q21. What is Encapsulation explain in details with valid example code?

Encapsulation is binding different attributes and methods with class. The attributes have different access leveles. They are public, protected and private.
Public attributes and methods can be acceeses by any child class or user. Protected attributes, methods can be accessed by only direct child class. This is for internal use of class, users of the class need not know about this.
private attributes and methods cant be access by anyone except the class itself. They are mostly builtin functions.
