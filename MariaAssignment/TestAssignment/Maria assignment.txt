Qno19 What is polymorphism ?
Ans-
Polymorphism means a child class redefines a method that already exist in the parent class.
class Animal:
    def sound(self):
        print("Animal makes sound")
class dog (Animal):
    def sound(self):
        print("bark")
class cat (Animal):
    def sound(self):
        print("Meao")

d = dog()
d.sound()

c = cat()
c.sound()
