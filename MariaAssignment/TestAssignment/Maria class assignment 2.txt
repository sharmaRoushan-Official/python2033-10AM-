#Q21. Extract all vowels from the string using list comprehension: text “Comprehension”?
ANS:-
## Method 1:
text = "Comprehension"
vowels = []
for i in text:
    if i in "aeiouAEIOU":
        vowels.append(i)
print(vowels)
## Method 2: Using list comprehension.
text = "Comprehension"
[i for i in text if i in "aeiouAeiou"]

#Q20. Write a lambda that checks if a string starts with “A”? [“apple”,” carrot”,” Apple”]
ANS:- 
b = ["apple","carrot","Apple"]
start_with_A = lambda s:s.lower().startswith("a")
result = list(filter(start_with_A,b))

#Q4. How many types of Inheritance? Name them.
ANS:-
# There are 5 types of Inheritance in OOPs:
1) Single/Simple Inheritance:- A single child class inherits from single parent class.
2) Multiple Inheritance:- A child class inherits from more than one parent class.
3) Multilevel Inheritance :- This inheritence goes from level to level.
4) Hierarichal Inheritance :- In this type of inheritance many child class inherit from a single parent class.
5) Hybrid Inheritance :- It is a combination of two types of inheritance
   example: Hierarichal inheritance + Muptiple inheritance
             Multiple Inheritance + Multilevel Inheritance
